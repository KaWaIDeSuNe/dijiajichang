   **5-10块/月**：动力港(8元/100G)、淘气兔(7.8/100G/月)、星河云(8/100G/月)、阿拉丁(10/158G/月)

   3)**需要小流量月付套餐**(每月50G以下)：
   星河云(1元/7G/月)
   
   3)**需要不限时按量付费套餐**：
   牛逼机场(13.9元/200G)、牛逼机场(35.9元/2000G)、动力港(30/100G)、淘气兔(22元/100G)、淘气兔(66元/400G)、五毛机场(24元/1000G)、五毛机场(68元/5000G)、五毛机场(88元/10000G)
